# Lab - Personalized Power BI Agents

⏱️ Duration: 90 minutes

This lab shows how to extend and personalize agentic Power BI development. You will use skills, MCP capabilities, PBIP, and code-first tooling to customize agent behavior, encode team standards, and apply your own modeling best practices across semantic models and reports.

## What you will learn

- How agent **skills and instructions** control behavior
- How to customize skills with your team’s modeling standards
- How to use **PBIP**, Git, and development tools in agentic workflows
- How MCP and Power BI authoring tools extend what agents can do
- How customized agents support both existing and new projects
