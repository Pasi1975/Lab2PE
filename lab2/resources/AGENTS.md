## Important

- For semantic model changes always load the `semantic-model-authoring` skill
- For report changes always load the `powerbi-report-authoring` skill
- Avoid direct edit of TMDL files. Instead use the Power BI Authoring MCP that is capable of connecting to the PBIP folder and/or Power BI Desktop.
- When asked to modify the semantic model, default to connect to the PBIP folder instead of the Power BI Desktop local instance.
- When asked to document the project, make sure to load and use the skill `powerbi-documentation`
